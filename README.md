# XPath Assistant

A Chrome DevTools extension for **web element inspection, XPath generation, and test automation support**.

### Features

* Capture and inspect webpage elements
* Generate XPath and CSS selectors
* Evaluate selector confidence and match count
* Recommend automation actions based on element type
* Build and copy ZeuZ-compatible automation steps
* Chrome DevTools integration

### Tech Stack

**TypeScript · React · Chrome Extension API · Zustand · Webpack · Tailwind CSS · Vitest**

### Run / Test

The repository includes a ready-to-use build in `dist/`.

1. Open `chrome://extensions/`
2. Enable **Developer mode**
3. Click **Load unpacked**
4. Select the `dist/` folder
